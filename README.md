# 🤖 Code Mentor

### AI-Powered Python Code Learning Assistant

Code Mentor is a Python-based learning assistant that helps beginners understand,
analyze, debug, and improve their Python programs.

---

## 🚀 Features

- 🔍 Syntax Error Detection
- ⚠️ Runtime Error Detection
- 📖 Code Explanation
- ✨ Code Quality Analysis
- 🛠 Smart Fix Suggestions
- ⚡ Time & Space Complexity Analysis
- 📤 Program Output
- 🤖 Mentor Feedback
- 🎨 Interactive and Responsive Web Interface

---

## 🛠 Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- Python AST (Abstract Syntax Tree)
